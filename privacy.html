Кто мы

Not a Gentleman — YouTube-канал о нейросетях и технологиях. Этот сайт и связанное с ним приложение «YouTube Autopilot» используются владельцем канала для публикации собственных видео.

Какие данные обрабатывает приложение

Приложение «YouTube Autopilot» обращается к YouTube Data API от имени владельца канала и только к его собственному каналу. Оно загружает видео, устанавливает обложки и метаданные и читает список популярных видео для подбора тем. Приложение не собирает, не хранит и не передаёт третьим лицам данные других пользователей YouTube или Google.

Использование данных Google

Использование и передача приложением информации, полученной через API Google, соответствует Google API Services User Data Policy, включая требования об ограниченном использовании (Limited Use).

Хранение данных

Токены доступа к YouTube хранятся локально на компьютере владельца канала и используются только для публикации видео. Данные посетителей этого сайта не собираются: сайт не использует cookie, аналитику и формы.

Отзыв доступа

Владелец аккаунта может в любой момент отозвать доступ приложения на странице разрешений аккаунта Google.
